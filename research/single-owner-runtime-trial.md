# Single-owner runtime trial

Use one existing low-stakes workflow for 14 calendar days. Record the start
date, domain and exact query fields before the first live consultation.
Run in memory-only mode in a separate local vault. Keep the agent in advisory
mode and let the owner execute any action. Use only genuine owner records for
the two-record fast path. Keep third-party messages and identifiers out of
the vault.

Prespecify a 50% blind audit of fast-path approvals using the existing
judgment settings and elicitation inbox. The owner answers each audit before
seeing the recommendation. Record the number invited, completed and correct,
and report agreement on completed audits with counts. Report any missing
audits. Also record eligible queries, fast-path approvals and owner referrals
by day. Include days with zero traffic.

Alongside live consultations, stage unchanged controls and one-field
mutations of actual prior cases. Freeze the changed-circumstance label
before asking the agent. Report changed cases that received a fast-path
approval divided by all changed cases. Keep staged probes separate from
live traffic. Treat a different action, option, recipient, price, deadline
or condition as consequential when it changes the owner's preferred action
or the decision's scope. Pause on the first consequential false approval.

Time active owner review from reading the case to submitting a choice.
Report total and median daily review minutes, escalation counts, and the
number left unanswered. Close after day 14. With fewer than 20 completed
blind audits or 20 changed probes, report the counts as insufficient for
a performance conclusion. This trial describes one owner's workflow.

For an independent non-pricing benchmark, the ANES 2016-2020-2024 merged
panel offers three dated observations and a repeated-variable catalog.
Freeze item wording, response harmonization, eligible categories and
participant splits using the codebooks and early waves. Use 2016 and 2020
as history and 2024 as the target. Evaluate exact-repeat two-record agreement
and a prespecified one-parameter personal tendency separately. Compare with
an independent participant majority on matched cases and include shuffled
identity and participant bootstrap intervals. Report panel-only results
unless the analysis accounts for the survey sampling design.

Source: [ANES merged panel and codebooks](https://electionstudies.org/data-center/2016-2020-2024-panel-merged-study/).
